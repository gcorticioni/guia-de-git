# merge

(a definição entra aqui, na rodada 2)
Uma branch é uma ramificação do projeto que permite desenvolver novas funcionalidades ou corrigir erros sem alterar diretamente a versão principal do código. Ela facilita o trabalho em equipe e permite testar mudanças de forma independente. Por exemplo, no Git, o comando git branch nova-funcionalidade cria uma nova branch para desenvolver um recurso.
